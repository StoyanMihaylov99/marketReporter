# marketReporter

A Spring Boot application that pulls market data from external APIs, runs it through an AI model, and returns clear, actionable insights about the current market situation.

Disclaimer: Output is generated by an AI model for informational purposes only. It is not financial advice.


### Overview

Market Scan AI does three things:

Collects market data (prices, volume, indicators, news) from external providers.
Normalizes and enriches it into a consistent internal model.
Analyzes it with an LLM and returns a structured summary: trend, key movers, risks, and a short outlook.

The goal is to turn raw market noise into something a client can read in under a minute.

---
### Features (Planned)

* Pluggable market data providers (stocks, crypto, futures) behind a common interface
Scheduled scans plus on-demand scan endpoint.
* AI-generated summaries with a structured, validated output.
* Caching layer to respect provider rate limits and cut costs.
* Dockerized for reproducible local and production runs.
* MCP server exposing market tools to AI clients
